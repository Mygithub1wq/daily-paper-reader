## 摘要
时序逻辑（TL）提供了一种组合语言，用于制定长视野机器人任务，但现有的基于时序逻辑的轨迹生成器可能通过在任务图中编码精确的物体几何信息来回避感知到符号的绑定。我们引入了\emph{Vision-TL-Action}，它从多视角图像、无坐标的时序逻辑语法图和机器人初始状态生成动作轨迹。通过双向交叉注意力融合TL节点令牌和空间视觉令牌，所得表示用于调节流匹配轨迹生成器。视觉令牌仅增加归一化图像平面位置和相机视角标识，而仅在训练时使用的谓词到区域目标鼓励对引用对象的接地。与先前工作一致，我们使用Success@$K$评估模型，即K条采样轨迹中至少一条满足时序逻辑规范的任务比例。在Panda任务上，我们的模型在Success@1024上达到67.45%，而oracle状态基线为59.11%。在AntMaze任务上，它在Success@256上达到96.35%，与oracle结果96.88%相当。分辨率和干预研究表明，空间细节依赖于语义接地，谓词身份同时影响注意力和性能。这些结果展示了从视觉观察和结构化时序逻辑目标到动作轨迹的直接映射，而无需在推理时使用物体几何信息。代码可在https://github.com/AricLau07/vision-tl-action获得。

## Abstract
Temporal logic (TL) provides a compositional language for the formulation of long horizon robotic tasks, but existing TL-conditioned trajectory generators can sidestep perception-to-symbol binding by encoding exact object geometry in the task graph. We introduce \emph{Vision-TL-Action}, which generates action trajectories from multi-view images, a coordinate-free TL syntax graph, and the robot initial state. TL-node tokens and spatial visual tokens are fused through bidirectional cross-attention, and the resulting representation conditions a flow-matching trajectory generator. Visual tokens are augmented only with normalized image-plane locations and camera-view identifiers, while a training-only predicate-to-region objective encourages grounding to referenced objects. Consistent with prior work in this domain, we evaluate the model using Success@$K$, the fraction of tasks for which at least one of K sampled trajectories satisfies the TL specification. On Panda task, our model achieves 67.45% Success@1024, compared with 59.11% for the oracle-state baseline. On AntMaze task, it achieves 96.35% Success@256, comparable to the oracle result of 96.88%. Resolution and intervention studies show that spatial detail depends on semantic grounding and predicate identity affects both attention and performance. These results demonstrate a direct mapping from visual observations and structured TL goals to action trajectories without requiring object geometry at inference. Code is available at https://github.com/AricLau07/vision-tl-action.

## 二、方法论

**核心思想：**

将 STL 规范编码为「无坐标」语法图（仅保留算子类型、时间区间、谓词类型、物体身份等符号信息，不含坐标/尺寸），将多视角图像编码为「可寻址」的局部视觉 token，通过**双向交叉注意力**实现图-视觉信息融合，所得融合特征与初始机器人状态共同条件一个**流匹配（Flow Matching）轨迹生成器**。训练时额外引入「谓词到区域接地」的辅助监督，鼓励物体引用型谓词节点关注对应物体所在图像区域。

**关键技术细节与流程：**

1. **无坐标 TL 图编码**
   - 每个物体身份用可学习嵌入表示：`eobj: Lobj → R^dobj`，替换掉原始图节点中的标量物体 ID。
   - 初始节点表示：`f_v = [Ltype, t_start, t_end, Lap, eobj(Lobj), Lshape, Lleft]`，不含任何度量几何。
   - 使用 Lg 层图卷积编码器 `ETL` 传播信息，保留每个 TL 节点的最终表示作为独立 token，不立即池化。

2. **可寻址多视图视觉 Token**
   - 共享视觉骨干网络逐个处理各视角图像 `I(c)`，得到局部特征网格。
   - 每个视觉 token 附加一个地址 `s_j = [ξ_j, η_j, ν_j]`，其中 `(ξ, η)` 为归一化特征网格坐标，`ν` 为归一化视角标识，地址经线性投影后加到内容 token 上（初始化为零）。
   - 地址编码不含符号物体身份或度量世界坐标，只提供空间位置与视角信息。

3. **图-视觉双向交叉注意力（核心融合模块）**
   - 两个双向层 × 4 头（d_h = d/4）。
   - **TL→Vision 方向**：每个 TL 节点 token 查询视觉 token，注意力矩阵 `A^{g←v}` 决定每个谓词节点从哪些图像区域获取证据。
   - **Vision→TL 方向**：视觉 token 反过来查询更新后的 TL 节点 token，实现双向语义对齐。
   - 输出经掩码均值池化与投影，得到融合特征 `fgv`。

4. **谓词到物体接地目标（训练时监督）**
   - 对最终层 TL→Vision 注意力在 4 头上求平均，得到 `A_ij`。
   - 接地损失：`L_ground = -1/|Q| Σ log(max(Σ_{j∈R_k(i)} A_ij, ε))`，鼓励每个物体引用型谓词节点将注意力质量集中到该物体中心投影所在的视觉 token 上。
   - 该监督使用训练时特权投影信息，推理时完全不需要。

5. **流匹配轨迹生成**
   - 沿用 TeLoGraF 的条件流匹配 Temporal U-Net。
   - 条件向量 `c = [fgv; Eq(q0)]`，学习条件向量场 `vθ`，训练目标为 `L_FM = E‖vθ(c,s,τ̃s) − Δτ‖²`。
   - 总损失：`L = L_FM + λg·L_ground`。
   - 推理时从高斯噪声出发，用 N_s 步欧拉法求解 ODE，反归一化得到候选轨迹。

## 六、主要结论与发现

1. **视觉观测可以替代精确物体几何**：在 Panda 上 Vision-TL-Action 甚至**超过**了 oracle state 基线（67.45% vs 59.11%）；在 AntMaze 上基本持平（96.35% vs 96.88%）。物体几何并非 STL 条件轨迹生成的必需输入。
2. **单样本质量与候选集覆盖是两种不同属性**：oracle 模型单样本成功率更高（样本更集中），但视觉模型的采样覆盖更广，随 K 增大可以追平乃至反超。这意味着不能用最大候选集覆盖直接推断可部署的 top-1 性能。
3. **接地监督有效**：训练时的谓词到区域接地损失显著提升了图-视觉注意力对齐（Panda 上 dominance 0.231→0.341，top-5 hit 0.487→0.978，ID-swap shift 0.019→0.317），且通过交换图内物体 ID 的干预实验证明注意力确实跟随谓词身份变化。
4. **位置编码与接地监督互补**：单独使用任一模块增益有限，二者结合才能产生协同效果；在 token 分辨率不足（4×4 碰撞严重）时两者都无法恢复性能，凸显了空间分辨率的前提作用。
5. **任务类型存在差异**：视觉模型在 AND/OR 与 until 类任务上超越 oracle，但在 sequential（顺序）任务上仍落后——精确状态在需要严格次序推理的任务上保留了优势。
6. **身份-颜色一致性是接地的重要前提**：在固定身份颜色协议下，Panda 的 Success@1024 提升 12.67 pp，说明稳定的视觉身份线索对感知-符号绑定至关重要。

## 七、优点

1. **问题定义清晰、切中要害**：明确指出现有 TL-条件轨迹生成依赖特权几何信息的缺陷，并以「无坐标 STL 图 + 多视图图像」为输入重新定义问题，填补了视觉-符号绑定在这一领域的空白。
2. **神经符号融合设计巧妙**：双向交叉注意力允许 TL 谓词节点主动检索相关图像证据，同时视觉 token 也能反向获取任务结构信息，比单向条件化更利于语义对齐。
3. **训练时接地方案务实有效**：利用训练期可用的物体投影作为弱监督信号，在推理时完全移除，兼顾了监督效率与部署无特权性。
4. **实验体系非常完整**：从主结果到视觉干预、身份干预、分辨率诊断、数据量控制、训练时长控制、公式族分解、失败案例保留，层层递进，形成严密的证据链。
5. **统计严谨性突出**：三种子均值、task bootstrap 置信区间、符号翻转检验、配对分析、开发记录与正式证据明确分离，可信度高。
6. **诚实的局限讨论**：明确指出训练集/评估集中仍存在特权信息（投影监督、ground-truth 鲁棒性评估、语义栅格输入），未过度宣称「完全部署可用」。
7. **代码开源**，有利于复现与后续研究。

## 八、不足与局限

1. **训练与评估中仍残留特权信息**：接地损失 L_ground 依赖物体中心的投影标注（训练时特权），评估使用模拟器 ground-truth 几何计算 STL 鲁棒性。作者也承认「完整部署系统」仍需额外组件。
2. **Success@K 不是可部署指标**：该指标衡量候选集覆盖而非实际选择能力。单样本成功率较低（Panda @1 仅 3.39%），缺少一种「从 K 个候选中选出正确轨迹」的排序/筛选机制，实际部署前需学习式轨迹排序器。
3. **AntMaze 使用语义栅格而非真实 RGB**：视觉输入是合成的语义栅格图像（迷宫地图 + 任务目标），避开了自然图像的复杂光照、遮挡、纹理等挑战，视觉接地难度的代表性有限。
4. **顺序任务上的劣势**：在 sequential 类任务上视觉模型显著落后于 oracle（Panda 76.92% vs 93.59%；AntMaze 87.88% vs 100%），说明当前方法对「严格顺序依赖」的视觉符号推理仍不充分。
5. **固定迷宫地图的先验吸收问题**：AntMaze 中移除 map 视图后性能几乎不降（96.88%→95.31%），表明模型将固定环境结构吸收进了先验，虽然任务目标视图仍起决定性作用，但这也意味着该方法对「环境结构变化」的泛化能力需要进一步验证。

## 八、不足与局限（续）

6. **未做真实世界验证**：仅在模拟器（Panda / AntMaze）中验证，未在真实机器人或真实场景中部署测试。仿真环境（尤其是 AntMaze 的语义栅格与 Panda 的固定渲染管线）与真实世界的视觉噪声、光照变化、物体纹理差异之间存在显著鸿沟，方法的实际部署可行性尚未得到证明。
7. **评估任务集规模相对有限**：Panda 与 AntMaze 分别仅有 128 个和 64 个固定 holdout 任务，虽然公式族覆盖较广，但任务组合空间仍然巨大，难以覆盖所有可能的 STL 嵌套与物体组合模式。
8. **位置编码与地址设计的局限性**：视觉 token 的地址仅包含归一化网格坐标与视角标识，不包含任何语义信息。这种方法在固定/已知相机几何的仿真环境下有效，但对于相机位姿变化、透视形变、多机器人共享观测等场景，地址编码的表达力可能不足。
9. **对视觉观察的依赖具有片面性**：AntMaze 中模型几乎完全依赖任务目标视图，对迷宫地图视图的利用不足（移除后性能几乎不降），说明模型缺乏主动整合多元观测信息的机制，而仅仅是「挑一个最有用的视图」。
10. **接地监督的粒度较粗**：L_ground 仅监督物体引用型谓词节点对应物体中心的全局注意力集中度，未约束注意力分布的局部形状（如高斯弥散）、多物体区分度（同一区域多个物体交叠时）或视觉 token 网格的细粒度边界，对于密集场景的接地鲁棒性仍有提升空间。

## 九、改进建议与未来研究方向

1. **引入轨迹排序/选择机制**：鉴于 Success@K 衡量的是候选集覆盖而非部署性能，可学习一个「轨迹排序器」，从 K 个候选中挑选最终执行轨迹。排序器可基于 STL 鲁棒性预测器或融合模型置信度进行训练，将候选集优势转化为 top-1 性能。
2. **向真实世界迁移**：在真实机器人平台上验证，结合域随机化（domain randomization）与真实感渲染（如表 4 中 Legacy vs Unique 颜色协议的对比表明渲染协议对性能影响显著），增强视觉编码器对真实感知分布的鲁棒性。
3. **提升顺序任务表现**：针对 sequential 类任务严格落后于 oracle 的问题，可在图编码器中引入时序因果掩码或显式的任务阶段推断模块，帮助模型把握「完成前一子目标后再推进下一目标」的次序依赖。
4. **自适应分辨率与稀疏注意力**：在 8×8 与 16×16 token 网格间存在性能差距（Panda 从 60.61% 提升至 80.55%），可探索基于任务难度的自适应分辨率选择或注意力稀疏化，在保持性能的同时降低计算开销。
5. **扩展视觉预训练**：当前视觉骨干为随机初始化训练，若接入大规模预训练的视觉-语言模型嵌入，可能提升对自然场景的理解与物体识别能力，尤其在真实世界迁移场景下。
6. **引入多视角主动感知**：允许模型在需要时主动请求特定视角的图像或调整相机位姿，减少对固定多视角配置的依赖，同时增强对遮挡与视角失效的鲁棒性。
7. **消除训练期特权投影信息**：用自监督伪标签（如视觉基础模型的指代分割）替代物体中心投影标注，使接地监督本身也脱离特权信息，向全无特权训练迈进一步。

## 十、总体评价

本文是一篇**问题意识强、技术方案完整、实验证据充分**的时序逻辑轨迹生成文献。它的核心贡献不在于某一项算法突破，而在于**重新定义了问题边界**——将"STL 规范→轨迹"的神经翻译从"特权几何依赖"推进到"纯视觉感知驱动"，并用严谨的对照实验证明了这一路径的可行性。

值得肯定的是，作者在论文中多处体现的学术审慎态度：明确区分正式主效应与辅助诊断、保留失败案例与性能差距、承认训练/评估中残留的特权信息、将开发过程记录与正式实验分离。这些都使其结论具有较强的可信度与参考价值。

与此同时，本文的局限性也决定了它更应被视为"可行性的证明"而非"部署级解决方案"：真实世界迁移、top-1 轨迹选择、顺序任务推理等关键问题仍需后续工作填补。但无论如何，Vision-TL-Action 为神经符号规划领域提供了一条值得延续的研究路线——以结构化语法图与可寻址视觉特征之间的双向交互为核心，逐步逼近"感知→符号→行动"的统一框架。
