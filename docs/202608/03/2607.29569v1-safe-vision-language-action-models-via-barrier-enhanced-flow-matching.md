## 摘要
本文提出了一种模块化推理框架，将流匹配生成模型与形式化控制屏障函数（CBF）安全保证相结合。与现有方法对模型最终输出应用外部安全过滤器不同，我们的方法修改了模型内部的流匹配去噪过程，以固有地生成安全轨迹。通过采用平滑的对数-求和-指数聚合屏障，我们在整个动作块上强制实施安全性。这种聚合屏障确保计算开销增加最小，并且不改变模型的语义意图。我们证明，在所提出的框架内，生成分布与目标分布之间的2-瓦瑟斯坦距离保持有界。我们的方法无需特定于安全的数据集或昂贵的模型重新训练，为安全推理提供了一种通用解决方案。我们在两个机器人操作平台和一个二维导航基准上验证了该方法，确认了我们的框架能够在不降低模型成功率的情况下实现可靠的安全性。

## Abstract
This article presents a modular inference framework that integrates Flow Matching generative models with formal Control Barrier Function (CBF) safety guarantees. Unlike existing methods that apply external safety filters to a model's final output, our approach modifies the Flow Matching denoising process within the model to inherently generate safe trajectories. By employing a smooth Log-Sum-Exponential aggregate barrier, we enforce safety over entire action chunks. This aggregate barrier ensures a minimal increase in computational overhead and does not alter the semantic intent of the model. We show that, within the proposed framework, the 2-Wasserstein distance between the generated distribution and the target distribution remains bounded. Our method eliminates the need for safety-specific datasets or costly model retraining, providing a versatile solution for safe inference. We validate the approach on two robotic manipulation platforms and a 2D navigation benchmark, verifying that our framework achieves reliable safety without degrading the success rate of the model.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉语言动作（VLA）模型已成为机器人操控领域的前沿方案。模型规模从 RT-2-X（55B 参数）逐步缩减至 OpenVLA（7B）和 SmolVLA（550M），使得 VLA 模型的推理与微调变得轻量化。现代 VLA 模型（如 π0、SmolVLA）通常由 VLM 骨干 + Action Expert 双变压器结构组成，并采用 Flow Matching 生成式去噪过程来输出动作块。
- **核心问题**：尽管 VLA 模型具备强大的复杂任务规划能力，但其缺乏形式化的安全保证。现有安全过滤方法（如后置 CBF-QP 过滤器）作用在模型最终输出上，可能产生**分布外样本**、损害轨迹质量，且无法保证语义意图不变；而需要安全数据集或模型重训练的方法则成本高昂、不够通用。
- **研究目标**：在不改变 VLA 语义意图、不增加显著计算开销、无需安全数据集或模型重训练的前提下，将形式化的 CBF 安全保证直接**嵌入流匹配去噪过程内部**，使模型天然生成安全轨迹，同时维持任务成功率与生成分布质量。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 核心思想
- 将传统"生成后过滤"范式转变为**生成中强制安全**：在 Flow Matching 的 ODE 去噪过程中注入一个额外修正项 δ_s，通过 CBF-QP 求解最小修正量，使生成轨迹满足安全约束。
- 针对整个动作块（action chunk）定义安全，而非单一步态，并使用**Log-Sum-Exponential（LSE）平滑聚合**替代不可微的 min 算子，兼顾安全性、光滑性与计算效率。

#### 关键技术细节

1. **安全动作块定义（Definition 2）**：动作块 z = [q₁, ..., q_H] 安全当且仅当每个状态 q_i 均满足 h(q_i) ≥ 0。
2. **LSE 聚合屏障（公式 8）**：
   - h(z̄) = -1/κ ln(Σᵢ e^{-κh(qi)})，κ > 0 为平滑参数。
   - Theorem 2 保证其误差界：min h(qi) − lnH/κ ≤ h(z̄) ≤ min h(qi)，即 LSE 函数是对 min 算子的保守下逼近。
3. **修改流匹配 ODE（公式 11）**：dψs/dτ = v(τ, ψ(z, τ)) + δs，其中 δs 为安全修正项，仅在去噪后期（τ ∈ [τs, 1]）启用（因为早期中间状态是噪声，无物理意义）。
4. **CBF-QP 求解（公式 12、19）**：
   - 基础 QP：min ½‖δ‖²，s.t. ∂h/∂z(v_θ + δ) ≥ −αh(z)。
   - 最终 QP（公式 19）额外引入**速度约束**（通过稀疏矩阵 D 计算有限差分关节速度）和**平滑惩罚项** λ‖D(z̄ + (v_θ + δ)Δτ)‖²。
   - 闭式解（公式 13）：δs = ReLU(−αh(z) − ∇zh(z)v_θ(τ,z)) / ‖∇zh‖² · ∇zh，求解极其高效。
5. **理论保证**：
   - Theorem 3/Corollary 1：修改后的速度场 v̂_θ = v_θ + δs 仍满足 Regularity 条件，2-Wasserstein 距离上界保持有界（\bar{ε} < ∞），即安全修正不会导致严重分布偏移。
   - Theorem 4（可证明安全去噪）：假定最坏情况下屏障衰减率为 M，则当 τs ≤ h₀/M 时，生成的最终动作块满足 h(ψ(z,1.0)) ≥ (h₀ − Mτs)e^{−α(1−τs)} > 0，即安全性有形式化保证。
6. **兼容的屏障函数示例**：
   - 壁屏障（Wall Barrier）：h(q) = ⟨n, p_ee⟩ − d，用于约束末端执行器不过平面。
   - 球形屏障（Spherical Barrier）：h(q) = ‖p_ee − p_center‖² − r²，用于避开球形区域。
   - 二者均为纯运动学函数，无需动力学模型，适用于位置控制型机器人。

#### 算法流程（Algorithm 1）
1. 输入图像、语言 tokens、超参数（κ、α、τs）及屏障参数。
2. 采样初始噪声 z₀ ~ Beta 分布。
3. 对 τ 从 0 到 1.0 迭代去噪：
   - VLA 推理获得速度场 v_θ；
   - 若 τ ≥ τs：计算各 q_i 的 h 与 ∇h，利用 LSE 聚合得 h(z) 与 ∂h/∂z，求解 QP 得 δs；
   - 否则 δs = 0；
   - 更新 z_{τ+Δτ} ← z_τ + (v_θ + δs)Δτ。
4. 返回安全去噪后的动作块 z₁.₀。
