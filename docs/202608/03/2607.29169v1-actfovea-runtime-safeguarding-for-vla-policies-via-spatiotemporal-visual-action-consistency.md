## 摘要
视觉-语言-动作（VLA）策略在机器人操作中表现出色，但仍易受运行时扰动的影响，这些扰动会破坏视觉观察、机器人状态与执行动作之间的时间对齐。我们提出了ActFovea，一个即插即用的保护框架，无需重新训练或修改底层VLA策略即可检测并缓解此类故障。ActFovea利用机器人运动学、本体感觉状态和近期动作来构建动作条件下的中央凹区域，保留接触相关区域和预测运动走廊，同时抑制与任务无关的视觉内容。它通过评估视觉运动和观察新鲜度是否与几何、本体感觉及动作转换保持一致来检测运行时风险。对于可恢复的扰动，ActFovea构建针对扰动的候选观察，并在验证生成的动作块之后才接受恢复。当过时或重放的观察使可靠恢复变得不可能时，它会调用有界的安全失败程序。在跨多个LIBERO套件对π₀进行的闭环评估中，ActFovea在局部视觉叠加下的成功率从49.3%提高到90.3%，接近干净性能差距的93.7%。它进一步将动作漂移和视觉延迟下的成功率分别提高了7.0和9.8个百分点，同时保持干净任务性能。在冻结观察重放下，ActFovea在所有试验中均触发及时的安全失败，没有未受保护失败。这些结果表明，时空视觉-动作一致性为VLA策略的运行时保护提供了有效基础。

## Abstract
Vision-language-action (VLA) policies achieve strong performance in robotic manipulation but remain vulnerable to runtime disturbances that break the temporal alignment among visual observations, robot states, and executed actions. We introduce ActFovea, a plug-and-play safeguarding framework that detects and mitigates such failures without retraining or modifying the underlying VLA policy. ActFovea uses robot kinematics, proprioceptive states, and recent actions to construct action-conditioned foveated regions that retain contact-relevant areas and predicted motion corridors while suppressing task-irrelevant visual content. It detects runtime risks by evaluating whether visual motion and observation freshness remain consistent with geometric, proprioceptive, and action transitions. For recoverable disturbances, ActFovea constructs disturbance-specific candidate observations and accepts a recovery only after verifying the resulting action chunk. When stale or replayed observations make reliable recovery impossible, it invokes a bounded safe-failure procedure. In closed-loop evaluations of $π_0$ across multiple LIBERO suites, ActFovea increases success under localized visual overlays from 49.3\% to 90.3\%, closing 93.7\% of the gap to clean performance. It further improves success under action drift and visual delay by 7.0 and 9.8 percentage points, respectively, while preserving clean-task performance. Under frozen-observation replay, ActFovea triggers timely safe failure in all trials, with no unprotected failures. These results demonstrate that spatiotemporal visual-action consistency provides an effective basis for runtime safeguarding of VLA policies.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）策略在处理机器人操作任务上表现优异，通常采用**动作块预测**（action chunking）范式，一次预测多步动作以减少推理频率并保持运动连续性。
- **核心问题**：动作块设计使策略在两次观测之间执行多步控制，导致视觉观测、本体状态与执行动作之间的**时间对齐**极易被运行时扰动破坏。当对齐被打破时，策略会基于与当前物理状态不匹配的视觉证据做出决策，导致任务失败甚至安全风险。
- **现有方法的不足**：已有安全防护多针对单一扰动类型（如几何约束层、视觉干扰物抑制等），采用统一保守策略或一律按异常处理，缺乏判断**扰动类型**与**可恢复性**的能力，无法安全地区分"合理暂停"与"观测停滞"、"正常运动"与"轨迹漂移"。
- **核心洞察**：尽管扰动类型各异，它们共享同一种失败本质——**视觉内容、本体状态转移与动作演变不再共同描述一个连贯的物理演化过程**，即违反了"时空视觉-动作一致性"。

## 2. 方法论

### 2.1 核心思想

ActFovea 是一个**即插即用**（plug-and-play）的推理时保护框架，在**不重新训练、不修改底层 VLA 策略参数**的前提下，通过策略的观测-动作接口实施安全防护。核心思想是：利用机器人运动学、本体感觉、视觉历史与动作历史，来判断当前闭环回路是否自洽，并决定应该恢复还是安全失败。

### 2.2 主要技术模块

**（1）动作条件化注视区域（Action-Conditioned Foveation）**

- 不采用以图像几何中心为参照的固定注视，而是根据**机器人运动学投影**与**动作预测**动态构建注视区域：
  - 通过正运动学将当前及外推位形映射到夹爪中心，投影到图像平面得到接触中心 $c_t^v$；
  - 沿预测轨迹构建短运动走廊 $\Gamma_t^v$；
  - 采用**圆盘 + 走廊 + 膨胀**的组合得到保留掩码：$M_t^v = \text{Dilate}(M_{c,t}^v \lor M_{\Gamma,t}^v, r_m)$；
  - 对注视区外的背景施加归一化、高斯平滑与灰度混合等编辑，从而**抑制任务无关内容、保留接触关键证据**。

**（2）一致性监测与风险评估**

- 从多个维度评估观测与状态-动作演化的一致性：几何一致性（观测中心与投影接触中心的距离）、动态一致性（观测位移与预测位移的方向和幅度）、时间证据（时间戳健康度、局部运动缺失、滞后估计、全局重放相似度）以及动作-本体一致性。
- 综合风险分数：$R_t = \text{clip}(\beta \bar{r}_t + (1-\beta)r_t + p_{t}^{cam} + p_{t}^{lag} + p_{t}^{cal}, 0, 1)$，包含滞后惩罚与传感器健康惩罚。
- 确定性路由器根据证据将状态分类为：一致、空间异常、时间延迟、动作漂移、冻结/重放、未知。

**（3）扰动条件化恢复与候选观测银行**

- 对可恢复扰动构建**候选观测银行**：原始观测、注视滤波后观测、时间对齐候选（延迟时）、空间去叠加候选（局部叠加时）。
- 局部视觉叠加的空间恢复：利用最后一次干净参考帧与首帧叠加帧的关系估计叠加图案 $\hat{Q}_t^v$ 与混合系数 $\hat{\alpha}_t^v$，重建干净区域 $\hat{X}_t^v = \text{clip}\left(\frac{P_t^v - \hat{\alpha}_t^v \hat{Q}_t^v}{1-\hat{\alpha}_t^v}, 0, 255\right)$，并用高斯羽化处理边界。

**（4）动作块验证**

- 对每个候选观测产出的动作块，检查首动作方向、端点方向、运动幅度、平滑度、时域跨度与块内漂移，综合为验证分数 $V_k = \text{clip}(w^\top u_k + b_k, 0, 1)$，只有验证通过的动作块才被允许执行。
- 验证器对候选优先级、执行模式、恢复强度进行多阶段抉择，作为保守的**共享验收闸门**。

**（5）风险自适应执行与安全失败**

- 两级仲裁：监测器（决定保持执行、阻尼、缩短时域或保持）与验证器（决定正常、短时域、伺服恢复或安全失败）。
- 综合执行决策：$\hat{a}_{t,i}^{mot} = \lambda_{t}^{mon} \lambda_{t}^{ver} a_{t,i}^{\star, mot}$，$h_t = \min(h_t^{mon}, h_t^{ver})$。
- 若冻结观测重放证据持续存在（触发"保持闩锁"），则**禁用恢复，进入有界安全失败**——预先附加一个截断的反向动作后填充保持动作，终止任务执行。

## 3. 实验设计

- **Benchmark**：LIBERO 基准的四个十任务套件——LIBERO-Spatial、LIBERO-Object、LIBERO-Goal、LIBERO-10，总计 **40 个任务**。
- **基础策略**：使用冻结的 π₀ LIBERO checkpoint，每任务 50 个 episode，每个方法-场景单元共 **2,000 个 episode**。
- **扰动设置**（四种扰动类型）：
  - **平滑动作块漂移**（Action Drift）：按任务家族相位模板扰动动作块的机动部分；
  - **多视角视觉反馈延迟**（Visual Delay）：外景与腕部视图滞后当前本体状态 3 帧；
  - **持久局部视觉叠加**（Visual Overlay）：在干净预热后向两个相机流混入固定局部棋盘格图案；
  - **冻结观测重放**（Frozen-Observation Replay）：触发帧在两个视角中反复复用直至终止。
  - 方法只能看到扰动后的观测与标准运行时输入，不提供扰动标签。
- **对比方法**：
  - Base VLA（无防护）；
  - Action Clip/Smoothing（固定有界平滑规则）；
  - Fixed Short Horizon（固定缩短重规划周期）；
  - Timestamp-Only Hold（仅靠帧龄与重复图像证据挂起执行）；
  - ActFovea 的几种消融变体（去除威胁类型判定、去除恢复银行、去除候选扩展、去除动作验证）。
- **指标**：任务成功率（SR）、绝对防御增益（Gain）、**归一化恢复率**（NRR，衡量恢复了多少因扰动导致的性能损失）。冻结重放场景使用任务成功 / 及时安全失败 / 未受保护失败的三分类结果。

## 7. 优点

- **统一框架**：以"时空视觉-动作一致性"为统一原理，将空间腐蚀、时间错位、动作漂移、观测重放纳入同一监测-恢复-安全失败管线，避免针对每种攻击单独设计防御。
- **即插即用**：冻结策略参数，仅通过观测-动作接口干预，适用于已有部署系统。
- **动作条件化注视**：注视区域跟随预测交互位置运动，而非固定图像中心，保留了接触区域和运动走廊相关的关键证据，设计巧妙。
- **可恢复性判断**：不仅检测异常，还区分可恢复与不可恢复，避免过度干预合法行为，也避免在失去可靠感知后依然延宕。
- **验证闸门**：所有恢复候选必须通过动作块验证，为恢复增加了一层保守的验收机制，提高安全性。
- **实验设计严谨**：多维度指标、消融完整、对比方法合理，安全失败质量也有定量评估。

## 8. 不足与局限

- **环境覆盖有限**：仅在 LIBERO 模拟环境验证，未在真实机器人硬件上测试，模拟与真实世界之间在视觉噪声、延迟特性等方面存在差距。
- **策略单一**：仅使用 π₀ 一个策略验证，结论对其他 VLA 架构（如 OpenVLA、RT-2）的推广性未经证明。
- **扰动人为构造**：四种扰动均由人为模板生成，模式相对规则，真实世界中扰动形态更复杂多变，未必能同样有效。
- **部分结果恢复率不高**：视觉延迟的 NRR 仅 59.8%，说明该场景下仍有相当一部分性能损失无法恢复；时间对齐的估计准确性可能成为瓶颈。
- **工程细节未能完全公开**：各组件分数的融合权重、校准方式、路由器阈值等为固定常数，其选择敏感性未详细讨论，复现存在一定难度。
- **安全失败不等同于正式安全保证**：论文明确指出有界运动抑制不提供正式的碰撞避免保证，安全失败策略在动态复杂环境中的适用性需要进一步验证。
- **绩效开销未量化**：实时性、计算量（尤其多候选验证重查询策略）等运行时开销未报告，可能影响真实部署可行性。
