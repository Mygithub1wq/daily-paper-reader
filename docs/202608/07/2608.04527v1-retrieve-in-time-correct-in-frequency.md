## 摘要
冻结的视觉-语言-动作（VLA）策略生成时间上扩展的动作块，但长视界操作仍然容易受到累积执行误差和跨任务阶段的视觉混叠的影响。成功的轨迹提供了有用的纠正证据，但当前的帧检索可能返回与进度不对齐的动作，而直接重放或时域融合可能覆盖策略提案的反应式结构。我们引入了“时间检索、频率校正”（RTCF），一个无需训练、测试时校正的框架，以较低的模型端开销提升冻结VLA的性能。RTCF将检索哪些经验与传递其动作的哪些部分分离开来。渐进式记忆对齐（PMA）通过逐步更新的单调前沿，将增长的视觉执行历史与完整的成功轨迹因果对齐，无需阶段标签即可联合识别相关记忆和当前对齐的记忆位置。从对齐的动作块中，RTCF在运动通道上传递一个按系数剪裁的低频残差。高频分量和夹爪决策仍继承自冻结策略。在四个LIBERO套件和每种条件2,000次试验中，RTCF将总成功率从86.4%提高到88.4%，并将LIBERO-Long从61.6%提高到68.6%。这些增益不需要参数更新、重复的VLA推理或额外的GPU资源：在单次策略调用后即可在客户端CPU上执行校正，每个动作块的中位延迟总计仅为10.99毫秒。

## Abstract
Frozen vision-language-action (VLA) policies generate temporally extended action chunks, but long-horizon manipulation remains vulnerable to accumulated execution error and visual aliasing across task stages. Successful rollouts provide useful corrective evidence, yet current frame retrieval can return progress-misaligned actions,while direct replay or time-domain fusion can overwrite the reactive structure of the policy proposal. We introduce Retrieve in Time, Correct in Frequency (RTCF), a training-free test-time correction framework that improves frozen VLA performance with low model-side overhead.RTCF separates which experience to retrieve from which part of its action to transfer. Progressive Memory Alignment (PMA) causally aligns the growing visual execution history with complete successful trajectories through incrementally updated monotonic frontiers, jointly identifying a relevant memory and the current aligned memory position without stage labels. From the aligned action chunk,RTCF transfers a coefficient-wise-clipped low-frequency residual on motion channels. Higher-frequency components and gripper decisions remain inherited from the frozen policy. Across four LIBERO suites and 2,000 episodes per condition, RTCF raises aggregate success from 86.4% to 88.4% and improves LIBERO-Long from 61.6% to 68.6%.These gains require no parameter updates, repeated VLA inference, or additional GPU resources: correction can be performed on the client CPU after a single policy invocation, and the median latencies sum to only 10.99 ms per action chunk

## 1. 核心问题与整体含义（研究动机与背景）

- **长期视野操作中的累积误差与视觉混叠**：冻结的视觉-语言-动作（VLA）策略虽然在单次测试中表现良好，但在部署时为持续闭环过程。长视界（Llong-horizon）操作中，微小局部误差会累积为后期失败，并且不同任务阶段可能出现视觉相似的观察（如接触前后目标配置相近），导致“视觉混叠”使单纯依赖当前帧的检索产生进度错位。
- **现有范式的不足**：已有记忆检索或重放方法通常直接检索视觉最相似的帧或直接重放整段记忆动作，但此类方法要么忽略了执行进度，要么会覆盖冻结策略的反应性结构（如执行途中遇到障碍需要即时调整）。学习残差模块或适配器则带来额外训练负担与模型复杂度。
- **核心问题**：如何在不更新参数的前提下，利用成功执行记忆，在测试时对冻结VLA策略进行低开销、进度感知、结构安全的校正？
- **文章回应**：提出 RTCF（Retrieve in Time, Correct in Frequency，“时间检索，频率校正”），将“检索哪些经验”与“传递动作的哪些部分”解耦，以训练免费的方式在客户端 CPU 上完成校正，无需额外的 VLA 推理或 GPU 资源。

## 2. 方法论：核心思想、关键技术与算法流程

- **整体思路**：RTCF 将记忆复用拆分为两个阶段：
  1. **检索阶段（Retrieve in Time）**：利用完整的执行历史，而非当前帧，定位成功记忆中与当前执行进度对齐的位置；
  2. **校正阶段（Correct in Frequency）**：将检索到的动作块作为先验，仅在频域转移低频运动残差，保留策略提案的高频细节与夹持器（gripper）决策。
- **记忆的紧凑存储**：
  - 视觉：冻结 SigLIP 最终层特征经 PCA 降维并 ℓ2 归一化，得到紧凑视觉描述子 zi,q；
  - 动作：复用 πFAST 的 BPE 词表，将动作块的 DCT 系数紧凑存为 token 序列，仅在校正时解码为频谱，降低存储需求。
- **渐进式记忆对齐（PMA）**：
  - 源于子序列动态时间规整（S-DTW），但改造为适合在线推理的因果、前沿保留（frontier-preserving）形式；
  - 对每条成功记忆维护动态规划前沿 Ji,t(q)：t 次策略调用后，查询序列的前缀以最小累计代价对齐到记忆位置 q 的代价；
  - 状态转移采用非对称因果模式：每个新观察只能分配一个记忆位置，当前位置保持不变或前跳 0≤δ≤vmax 步，并施加 γ|δ−1| 的软时间先验，偏好单位步进；
  - 开-begin 初始化：Ji,1(q)=ci,1(q)，允许对齐从记忆任意位置开始；开-end 通过选取前沿最小值端点作为对齐位置；
  - 归一化平均代价：d_i,t^PMA = Ji,t(b*)/t，用于跨记忆排序。
  - 无需阶段标签，也无需完整 DTW 矩阵，每次调用仅更新一条前沿，计算复杂度为 O(Σ_i L_i)。
- **频率选择性残差校正（Correct in Frequency）**：
  - 从对齐端点读取记忆中的未来动作块 umem，解码得到 DCT 频谱 Cmem；冻结策略提案同变换到 DCT 域 Cπ；
  - 定义校正掩码：仅保留低频率（0<f<Fc）且属于运动通道（非夹持器）的系数；
  - 转移裁剪后的残差：ΔC = G ⊙ clip(Cmem − Cπ, −δmax, δmax)，再以全局缩放 λ0 加回；
  - 最终动作由逆 DCT 得到：Ccorr = Cπ + λ0ΔC，不直接重放，也不覆盖高频与夹持器决策；若解码失败则直接使用原提案。
- **在线推理复杂度**：PMA 只需存储当前与上一条前沿，每调用一次 O(Σ_i L_i)；DCT 对为 O(DaH log H)；校正全程可在 CPU 上完成。

## 3. 实验设计

- **Benchmark**：LIBERO 套件，包含四个子套件：LIBERO-Long（长视界）、LIBERO-Spatial（空间关系）、LIBERO-Object（操作对象）、LIBERO-Goal（任务目标）。
- **策略与设置**：冻结 PI-FAST 策略（基于 π0-FAST），记忆库用 memory seed 7 预先收集成功轨迹，评估时冻结；测试时 RTCF 检索整个记忆库，无 oracle 初始状态过滤。
- **对比方法**：
  - 上区块为已有方法参考结果：Diffusion Policy、Octo、OpenVLA、CoA-VLA；
  - 下区块为受控对比（相同评估协议）：PI-FAST 冻结基线、Frame-NN（去掉历史对齐，仅当前帧对齐的消融）、Time-Domain（去掉频率选择，时域全残差转移的消融）、完整 RTCF。
- **评估规模**：每组条件 4 套件 × 10 任务 × 10 初始状态 × 5 种子 = 2000 集/条件。
- **指标**：成功率（SR）、绝对百分点差异、成功剧集变化；还配对统计 rescue（基线失败但修正后成功）与 regression（基线成功但修正后失败）。

## 4. 资源与算力

- **训练**：RTCF 本身是训练免费的（training-free），无需任何参数更新或模型训练，因此文中没有涉及训练时长或 GPU 训练算力。
- **部署资源**：
  - 硬件：单块 NVIDIA RTX 4090 GPU（仅用于基线策略前向）+ Intel Xeon Platinum 8358P CPU（2.60 GHz 基频，可至 3.40 GHz）执行全部新增计算；
  - 新增阶段全部在 CPU 上完成，包括 PMA 的精确检索和 FAST 未来动作读取；
  - 每动作块中位延迟：PMA 检索 p50 6.28 ms / p95 7.52 ms，FAST 读取 4.71 ms，合计 10.99 ms；动作可用延迟从基线的 386.47 ms 增至约 398.67 ms（约 +3.16%）；

- **注意**：论文未说明 PI-FAST 基线本身的训练数据、训练 GPU 数量或时长；只明确 RTCF 阶段无需额外 GPU 资源。

## 6. 主要结论与发现

- **总体性能提升**：RTCF 使冻结 PI-FAST 的成功率从 86.4% 提升至 88.4%（+2.0 个百分点），成功剧集从 1,727 增至 1,768。
- **最显著增益在长视界套件**：LIBERO-Long 从 61.6% 提升至 68.6%（+7.0 个百分点，净增 35 个成功）；Spatial +5 个成功、Object +2 个成功、Goal −1 个成功（近饱和的套件变化极小）。
- **任务级分析**：LIBERO-Long 中 10 个任务有 6 个改善、1 个持平、3 个回退；最大增益在 Task 5（46.0%→68.0%，+11 个成功）；6 个改进任务合计 +43 个成功，超过 3 个回退任务造成的 8 个失败。
- **组件互补性**：历史感知对齐和频率选择性校正是互补的：去掉历史对齐后 Long SR 降至 63.6%，去掉频率选择后降至 50.0%；后者在配对统计中产生更多的回归（92 对 47），说明无选择性的全残差转移反而更易破坏原本成功的提案。
- **核心启示**：记忆先验的价值在于“选择性传递”，而非覆盖或重放；高频分量与夹持器决策应保留冻结策略的响应结构。

## 7. 优点

- **训练免费、部署轻量**：无需更新参数、无需重复 VLA 推理、无需额外 GPU；单次策略调用后即可在 CPU 上完成校正，中位延迟仅约 11 ms，工程可行性高。
- **进度感知的因果对齐**：PMA 通过单调前沿增量更新，利用完整执行历史取代单帧检索，无需阶段标签即可消解视觉混叠与进度歧义，理论上有良好的在线性质（复杂度与记忆库规模线性）。
- **频率选择性校正的创新视角**：借助 DCT 分离运动趋势与局部细节，仅对低频率运动系数做有界残差校正，保留高频动作变化与夹持器决策，避免时域直接覆盖的破坏性。
- **严谨公平的实验设计**：匹配协议（同策略、同库、同种子、同状态清单）下的四条件对比、大规模评估（2000 集/条件）、任务级与配对级分析，结论可信度高。
- **透明地报告回退**：不回避少数任务和 Goal 套件的微小退化，并给出机制解释（近饱和任务提升空间有限、时间域校正会造成回归）。

## 8. 不足与局限

- **实验覆盖有限**：仅在 LIBERO 模拟环境中评估，未涉及真实机器人平台；所验证的 VLA 模型只有 PI-FAST（π0-FAST 架构），泛化到其他 VLA（如 OpenVLA、Octo、CoA-VLA）尚未验证。
- **记忆库规模与多样性受限**：每套件 500 集记忆（seed 7 下收集），未探索更大规模记忆库或跨任务库；记忆构建依赖成功轨迹的可得性，对失败率高或难以收集成功演示的任务可能受限。
- **参数敏感性与未调优空间**：超参数（频率截断 Fc、裁剪界 δmax、全局残差缩放 λ0=0.1、vmax、γ）均为固定值，论文未作详细敏感性分析，难以判断在不同任务或模型上的稳健性；λ0=0.1 虽然普遍适用，但最优值可能因任务难度而异。
- **效果分布不均衡**：少数任务出现明显回退，Goal 套件甚至有微小负收益；RTCF 对近饱和任务的增益很小，主要价值集中在长视界任务。
- **延迟测量部分为估计值**：动作就绪延迟是“阶段中位数估计”而非端到端直接测量，语义历史与 LF-noDC 阶段未单独计时，报告的总延迟仅覆盖两个主要环节，存在一定不确定性。
- **未讨论失败模式边界**：论文未深入分析当策略偏离记忆轨迹较远时，PMA 对齐失效的条件，以及校正是否会引入新的系统偏差。
