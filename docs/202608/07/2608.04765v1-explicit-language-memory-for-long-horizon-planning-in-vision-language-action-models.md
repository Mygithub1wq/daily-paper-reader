## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了统一范式。然而，现有VLA模型在长时程任务中仍面临重大挑战：稀疏的专家演示限制了跨任务组合泛化；长时程任务的非马尔可夫性质使得仅以当前观测为条件的策略难以维持时间一致性；有限的闭环纠错能力导致执行误差累积；端到端的动作微调可能削弱视觉-语言模型（VLM）骨干网络的高层语义表示。为解决这些问题，我们提出了一种带有显式语言记忆模块的分层长时程VLA架构。核心思想是将离散的时间观测转换为具有时间逻辑的连贯文本记忆序列。该系统被解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式进行语义推理，而低层VLA则根据子任务指令和视觉观测执行精确的连续控制。高层VLM以先前的记忆作为上下文锚点，递归更新语言记忆和子任务指令，从而在长时程执行过程中实现持续的时间跟踪和动态纠正。我们在多个仿真环境中评估了所提出的方法，并在真实机器人平台上进行了仿真到现实的实验。结果表明，显式语言记忆提高了VLA模型在复杂长时程任务上的成功率和鲁棒性，同时为决策过程提供了可解释的语义说明。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

- 核心思想是**将任务执行历史编码为显式自然语言记忆**：高层VLM基于全局指令、当前观测和上一时刻记忆，递归输出更新后的记忆和当前子任务；低层VLA依据视觉观测与子任务指令生成连续动作块。该方法解耦语义规划与连续控制，兼顾性能提升与可解释性。

## 2. 方法论：核心思想、技术细节与算法流程

- **层次化策略分解**：整体策略按概率分解为高层语义分支与低层动作分支：
  \[
  \pi(a_{t:t+H}, s_t, m_t \mid o_t, m_{t-1}, l) =
  \pi_{LL}(a_{t:t+H} \mid o_t, s_t) \cdot \pi_{HL}(s_t, m_t \mid o_t, m_{t-1}, l)
  \]
  高层分支决定“任务处于什么状态、下一步该做什么”，低层分支决定“如何执行该子任务”，两个分支各司其职、独立优化。
- **递归语言记忆（Recursive Language Memory）**：
  - 记忆 \(m_t\) 是结构化的自然语言摘要，涵盖已完成阶段、完成证据、相关物体属性、观测到的失败和下一步待办意图；
  - 采用**滚动压缩规则**：子任务未完成时，记忆保留帮助识别目标的关键细节（如物体类别、颜色、位置）；子任务完成后，细节被压缩为简短过去时陈述，注意力转向下一步；
  - 仅当当前观测提供阶段转变证据时，高层模型才更新记忆，避免了每一帧都重写历史。
- **自动化监督管线（Automated Memory Supervision）**：
  - 输入为专家视频 + 人工标注的技能名称、描述与起止时间戳；
  - 通用VLM以当前帧和完整技能标注为输入，自动生成两类目标：简洁子任务（形式为“动作+目标物体+场景上下文”）和第一人称语言记忆（过去时描述已完成技能，将来时过渡到下个技能）；
  - 提示词明确要求使用自然物体名和可观察属性，避免“帧”“序列”“索引”等实现性术语；论文报告了Gemini 3.5 Flash API与本地部署的Qwen3.5-9B两条标注路径。
- **独立分支训练**：
  - 高层分支采用**PaliGemma**，自回归联合预测更新的记忆与子任务，损失函数为：
    \[
    \mathcal{L}_{HL} = -\mathbb{E}\left[\log \pi_{HL}(m_t \mid o_t, m_{t-1}, l) + \log \pi_{HL}(s_t \mid o_t, m_{t-1}, l)\right]
    \]
  - 低层分支沿用π0.5的动作专家，采用流匹配（flow matching）目标，简化形式为：
    \[
    \mathcal{L}_{LL} = \mathbb{E}\left[\|a_{t:t+H} - \pi_{LL}(o_t, s_t)\|_2^2\right]
    \]
  - 两个分支独立训练，避免在单一目标函数中手动平衡语义生成与连续控制损失。
- **闭环推理流程**：记忆初始化为空，在每个决策步：获取观测 → 高层VLM更新记忆和子任务 → 低层VLA生成动作块 → 执行动作 → 根据高层终止条件判断是否结束。由于记忆和子任务均为可见文本，该循环天然产生可解释的决策日志。

## 3. 实验设计：数据、场景、基准与对比方法

- 实验覆盖**两类仿真环境**与**一个真实机器人平台**，相比原生π0.5基线：
  - **BEHAVIOR-1K 开关收音机任务**：给定指令“打开客厅桌子上的收音机”，机器人需定位并接近收音机、拾起、按按钮、放置桌面。任务细分为四个评估阶段：MoveTo、PickUp、PressOn、PlaceOn；
  - **Genie Sim 3.0 包裹分拣任务**：基于Isaac Sim的人形操作平台。单包任务包含六个计分阶段（Follow、PickUp、Inside-1、Upright、PickUp、Inside-2），机器人需跟随并拾取包裹、转向扫码区、条码朝上放置、再次拾取、放入蓝色料箱、复位；连续变体要求按任意顺序分拣四个不同颜色的包裹，每个包裹以条码朝上放入扫码区计为一个完成阶段；

- **评估指标**：**阶段级成功率（stage-wise success rate）**，对所有评估例子的所有阶段成功率取平均，能揭示长序列中失败发生的具体位置，而非仅报告端到端最终成功率。

## 6. 主要结论与发现

- **整体性能提升**：BEHAVIOR-1K平均阶段成功率从30.0%升至40.0%；Genie Sim单包裹从41.7%升至63.9%，连续分拣从31.3%升至46.9%；真实机器人从62.5%升至66.3%。
- **阶段一致性改善**：无记忆基线会在按按钮前就跳至“放置收音机”，或在扫码前跳至“放入料箱”；记忆策略只有在观测支持当前里程碑完成时才推进阶段，显著减少了跳步错误。
- **可解释性与错误定位**：显式记忆和子任务文本使决策日志可直接与动作失败对齐，能区分高层语义错误与低层控制错误。
- **支持上下文失败恢复**：真实机器人日志显示，抓取失败时记忆可记录“物体未被抓住”，并生成“重新张开夹爪再试”的子任务，而非陷入不一致状态直到超时，且不需要单独的恢复控制器。
- **语义记忆与底层控制能力互补**：语言记忆解决“该做什么”和“当前处于哪个阶段”，但不能解决“具体动作如何执行得好”。PressOn阶段成功率低说明接触密集动作仍需更强的底层控制与数据支撑。

## 7. 优点

- **层次化解耦设计**：高层语义规划与低层连续控制独立训练、独立优化，无需手工调节语义和控制损失之间的比例，也便于模块复用与替换。
- **显式滚动语言记忆**：同时具备紧凑性、有界性与可解释性，避免了直接拼接历史视觉帧的高计算成本，又保留了阶段转变所需的语义锚点。
- **自动化的监督数据管线**：利用通用VLM从专家视频与技能时间戳自动生成对齐的记忆和子任务目标，避免了繁重的人工标注，使表示可端到端训练。
- **递归更新机制**：只有观测到阶段转变证据时才更新记忆，使进度判断与真实状态绑定，有效抑制了过早推进。
- **多平台验证**：同时覆盖两个仿真环境与真实低成本双臂移动机器人，且真实实验验证了sim-to-real可行性。
- **实验分析维度全面**：除量化指标外，还从阶段一致性、语义规划与动作控制的边界、失败恢复等多个角度进行定性分析，诊断价值高。

## 8. 不足与局限

- **真实实验规模有限**：仅一个短时程拾取任务、25条训练轨迹、20次试验，未能在分钟级真实任务中验证多物体、重复交互或环境变化下的表现。
- **统计稳健性不足**：仿真结果未报告跨随机种子的方差或置信区间，改进幅度的统计显著性未知。
- **推理开销增大**：层次化设计在低层动作生成前额外引入一次高层VLM调用，增加端到端延迟、计算量和部署复杂度。
- **低层控制瓶颈未解决**：语言记忆无法补偿底层数据不足或控制精度有限，接触密集动作（如按按钮）的成功率仍然很低。
- **失败恢复依赖演示覆盖**：可靠的恢复行为需要演示中涵盖多样的失败与纠正轨迹，当前数据中此类示例有限。
- **记忆质量受标注VLM影响**：自动标注管线的质量依赖于通用VLM的生成能力，是否存在标注偏差或错误传播尚未讨论。
- **未来方向**：当前语言记忆是纯文本，无法承载视觉与触觉等物理交互信号；融合多模态记忆（视觉证据、触觉反馈、力信号）可提升状态估计可靠性，并配合更丰富的失败-恢复数据进一步提升长时程决策能力。
