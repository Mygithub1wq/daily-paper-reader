## 摘要
视觉-语言-动作（VLA）模型的视觉表征在空间精确的机器人操作中仍然不可靠。我们发现，VLA 中的视觉编码器也呈现出先前在通用视觉 Transformer 中记录的注意力伪影，并进一步表明，在具身策略中，这些伪影与后训练期间获得的空间感知能力密切相关。随着编码器学习任务相关信息（如物体位置、深度顺序和局部几何结构），有限的全局 token 容量导致部分信息溢出到低信息量的 patch token 中。我们提出 AtVLA，一个将可学习的寄存器 token 插入视觉编码器的框架。仅使用具身数据和原始动作目标进行端到端训练，这些寄存器成为具身空间信息的专用载体，而剩余的 patch token 恢复了干净且空间上忠实的注意力分布，这对于精确目标定位和细粒度接触至关重要。干净的注意力恢复了可靠定位，但无法恢复在低分辨率观测中丢失的几何细节。因此，AtVLA 将注意力修正与不确定性门控的局部细化相结合。动作专家采样多个动作块，并根据它们之间的不一致性估计不确定性；仅对不确定的预测，动作条件注意力展开识别任务相关区域，该区域被裁剪、以高分辨率重新编码，并附加到缓存前缀以生成细化动作。在 LIBERO、SimplerEnv 以及一个具有挑战性的单视图真实世界基准测试中，AtVLA 将 LIBERO 平均成功率从 94.2% 提升至 98.4%，真实世界成功率从 46.5% 提升至 69.0%。裁剪仅在约 30% 的重规划步骤中触发，在代表性部署设置下，总计算量仅为基础模型的 1.4-1.6 倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

# 论文详细总结：AtVLA

## 1. 核心问题与整体含义

- **研究动机**：视觉-语言-动作（VLA）模型虽然继承了大规模视觉-语言预训练中的丰富语义先验，但其视觉编码器在需要空间精确的机器人操作中并不可靠。常见的失败表现为无法正确定位目标物体、混淆任务类型，以及难以进行细粒度接触。
- **关键发现**：
  - VLA 的视觉编码器也存在通用 Vision Transformer（ViT）中已知的“高范数注意力伪影”：部分低信息量背景 patch token 被用作全局信息仓库，挤占局部空间内容，导致注意力图失真。
  - 这种伪影与具身后训练密切相关：编码器在学习物体位置、深度顺序、局部几何等任务信息时，有限的全局 token 容量不足以承载全部信息，部分信息“溢出”到 patch token 上，造成表征通道错位。
- **整体含义**：要提升 VLA 的空间操作能力，不能仅依赖语义理解，还需要修正视觉表征的注意力结构，并在必要时补充丢失的局部几何细节。AtVLA 正是为此设计的一套轻量级、可端到端训练的视觉精炼框架。

## 2. 方法论

### 总体框架

AtVLA 建立在预训练 π0 策略之上，包含两个互补机制：
1. **寄存器增强的视觉编码（Register-Enhanced Visual Prefix）**：在视觉编码器中插入可学习寄存器 token，用于吸收过多全局信息，恢复 patch token 的空间注意力。
2. **不确定性门控的局部视觉细化（Uncertainty-Gated Local Refinement）**：当动作预测不确定时，通过注意力引导裁剪任务相关区域，以高分辨率重新编码并追加到前缀中，生成更精确的动作。

### 关键技术细节

- **寄存器增强视觉编码**：
  - 输入序列构造：`Xt = [x_cls; r1, ..., rNr; p1, ..., pNb]`，其中 `Nr=4` 个寄存器 embedding 插入到 class token 之后，`Nb=256` 个 patch token。
  - 视觉编码器输出寄存器特征 `Rt` 和补丁特征 `Pt`，两者均通过视觉投影器送入前缀：`Cbt = [Π(Rt); Π(Pt); Elang(ℓ); Estate(s)]`。
  - 与原始寄存器方法只用作内部工作区不同，AtVLA **保留**寄存器输出作为下游策略的全局上下文，同时 patch token 保持干净的 16×16 空间网格用于接地（grounding）。

- **不确定性门控动作预测**：
  - 基于基础前缀生成缓存 KV，动作专家从独立高斯噪声采样 `K=4` 个动作块，执行 flow-matching 反演。
  - 计算近端平移动作维度的标准差作为不确定性：`Ut = mean over h steps and Dtr of std over K samples`。
  - 若 `Ut ≤ τ`，走默认置信路径，直接执行平均动作；若 `Ut > τ`，触发裁剪细化。

- **注意力引导局部细化**：
  - 从动作专家的 Joint-Attention 层中聚合注意力矩阵，进行 rollout 传播，得到 16×16 显著性图 `St`。
  - 使用对比窗口搜索：选择内部注意力与周围环形区域差异最大的方形窗口，避免全图裁剪或孤立峰值。
  - 将裁剪区域缩放至 224×224，用同一带寄存器的视觉编码器重编码；裁剪 patch token 加上位置编码（由 MLP 从归一化坐标生成）后追加到缓存前缀。
  - 注意：裁剪路径只有一个额外视觉编码和一次额外动作生成，基础前缀 KV 复用。

- **训练策略**：三阶段课程后训练
  - 阶段 0：寄存器适应（20K 步），先更新寄存器 token（4K 步），再解冻最后几个视觉层（16K 步）。
  - 阶段 1：真值裁剪对齐（10K 步），优化裁剪位置编码器和 LoRA，使策略学会解读裁剪 token。
  - 阶段 2：联合精炼与推理对齐（40K 步），联合优化 `L = Lπ0 + λ_cp L_cp + λ_ag L_ag`，并逐步从真值裁剪过渡到模型自身 rollout 产生的裁剪，同时引入裁剪 dropout（概率最高 0.3）。

## 6. 主要结论与发现

- **注意力伪影与后训练空间感知相关**：寄存器 token 在具身后训练中自发成为空间信息载体，线性探针显示其编码的物体位置、深度、表面法线等任务信息比 CLS token 和均值池化 patch 特征更强。
- **寄存器能修复注意力**：加入寄存器后可显著消除高范数伪影，使注意力集中到任务相关物体与交互区域，且这些清洁注意力能可靠地指导裁剪定位。
- **不确定性门控有效**：只有约 30% 的重规划步骤触发裁剪，既保证了精度又控制了额外计算。
- **性能提升显著**：
  - LIBERO 平均成功率从 π0 的 94.2% 提升至 98.4%；
  - 真实世界成功率从 π0 的 46.5% 提升至 69.0%；
  - 总计算量约为 π0 的 1.4–1.6 倍。
- **裁剪并非万能**：低质量外部裁剪反而可能干扰策略；在 Open/Close Drawer 这类大物体占据全图场景下，裁剪收益有限。

## 7. 优点

- **问题发现新颖且有深度**：将通用 ViT 的注意力伪影引入 VLA 评测，并与后训练中获取的空间信息建立因果关联，分析扎实。
- **方案轻量**：仅需额外 4 个寄存器 token（4608 参数）和一个小型位置编码 MLP，几乎不改变模型规模。
- **端到端可训练**：无需额外的视觉预训练或通用视觉监督，仅使用具身数据和原动作目标。
- **效率设计精妙**：不确定性门控 + KV 缓存复用 + 注意力 rollout 复用，使裁剪触发率低，额外成本有限。
- **真实世界验证强**：单视角、无额外传感器，贴近实际部署；20 次重复实验给出误差范围，可信度高。
- **课程训练策略细致**：分阶段对齐寄存器、裁剪分支和完整策略，避免不稳定特征漂移，并逐步将输入分布与推理对齐。

## 8. 不足与局限

- **基础模型单一**：验证基于 π0，未在 OpenVLA、RT-2、Octo 等其他 VLA 上测试，泛化性未知。
- **裁剪质量强依赖注意力**：当注意力本身仍被干扰或场景中目标区域过大时（如抽屉门），裁剪难以提供额外有效信息。
- **阈值与触发率需要手动校准**：针对不同机器人需要重新标定，增加了部署复杂度。
- **低分辨率信息损失不可完全恢复**：裁剪只对局部区域提分辨率，无法恢复整个场景中丢失的全局细节。
- **计算开销未完全透明**：文中只给出相对估算，缺乏实际端到端延迟、峰值显存、训练总时长等指标。
- **真实世界基准范围有限**：仅单臂、单相机、固定场景，未包含动态障碍、多机器人协作或复杂光照。
- **寄存器数量需搜索**：太少无法完全吸收伪影，太多可能收益饱和，实验中仅测试了有限范围，实际应用可能需要调参。
