## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现出色，但当标准指令仅被简单改写时，其性能会急剧下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探测表明，根本原因在于架构而非语义理解的缺乏。具体来说，我们证明当前的VLA模型内部能够成功保留正确的任务身份。失败实际上源于动态视觉观察与文本的联合编码，这引入了系统性的特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制命令。为解决这一结构瓶颈，我们提出了接地语义重绑定（GSR），这是一种优雅的干预方法，通过明确地将独立提取的任务语义与原生视觉特征融合，从零训练一个完全重新初始化的动作专家，从而绕过不稳定的联合路由。这种针对性的干预仅使用标准演示即可显著恢复改写不变性。在LIBERO-Para基准上，GSR将成功率提高了高达44.6%。它使轻量级模型能够与大规模缩放的基线相媲美，并将最先进的模型推至新的PRIDE纪录70.4分，在指令生成能力上超越了最近引入的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一个原生解耦的0.33B参数模型，展现出对指令改写的近乎完美的鲁棒性。最终，我们的工作证明，稳健的语义接地可以通过优雅的结构设计实现，绕过低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

- **核心问题**：本文追问这种脆弱性的**根本原因**——是模型没有理解改写后的指令，还是理解了却没有把语义转化为正确动作？
- **关键发现**：通过探针实验，作者发现模型**内部已经保留了正确的任务语义**（如 Retrieval@1 和语义保留指标显著高于随机），失败发生在“从语言/视觉联合表征到动作策略”的**架构性翻译环节**：动态视觉与文本的联合编码会引入系统性特征偏移，导致下游动作策略无法将已保留的语义映射为正确控制指令。
- **整体含义**：这项工作证明，鲁棒的指令语义接地可以通过**精巧的结构设计**实现，而无需依赖低效的数据扩展范式。这也为轻量级 VLA 模型追赶大规模模型提供了新思路。

## 2. 方法论
- **核心思想**：提出 **Grounded Semantic Re-binding（GSR）**——将“任务语义提取”与“视觉场景理解”解耦：使用冻结的 **T5-large** 编码器（不接收图像和机器人状态）提取纯任务语义，然后将该语义注入模型原生的多模态融合点，并与视觉、状态特征共同训练一个**完全重新初始化的动作专家**，从而绕过原生 VLM 中不稳定的联合语义路由。
- **关键技术细节**：
  - T5 输出 token 级特征，经可学习投影层映射到动作策略/多模态模型的宽度。
  - 对于原生语言路径脆弱的模型（如 VLA-Adapter、SmolVLA），将原生指令替换为固定中性句“perform the task”，迫使模型只依赖 T5 语义；对于原生语言路径已鲁棒的模型（如 π0.5），保留真实指令，T5 作为补充语义源。
  - 注入点**因架构而异**：VLA-Adapter 将 T5 特征作为旁路 K/V 注入 Bridge-Attention 动作块；SmolVLA 和 π0.5 则在 VLM 的多模态前缀/任务 token 处进行接地注意力融合（公式如 $\tilde{h}_{task}=h_{native-task}+g\cdot MHA(...)$），使语义与图像在原生计算中充分交互。
  - 动作专家从零训练，不微调冻结的 VLM/T5 主干。
- **公式与指标**：利用检索指标 Retrieval@1、语义保留率 $R = (\Delta_{wrong}-\Delta_{para})/(\Delta_{wrong}+\Delta_{para})$ 和层间干预恢复率 $1 - d_{act}(patch,c)/d_{act}(p,c)$ 来诊断语义保留和动作控制瓶颈。
- **ParaVLA**：进一步提出的 0.33B 原生解耦模型，用 T5 + DINOv2 分别编码语言和图像，仅在动作专家内部进行视觉-语言融合（无联合编码），训练时完全不使用改写数据。

## 3. 实验设计
- **数据集 / 场景**：
  - **LIBERO-Goal**：训练集（约 428 个 episode / 52,042 条 transition），只使用规范指令。
  - **LIBERO-Para**：主要评估基准，共 4,092 个 episode，分为 Act（870）、Obj（259）、Comp（2,963）三类改写，物理任务、初始状态和成功判定与原任务完全一致。
  - **Goal-100 诊断**：固定 100 个观测，配对规范指令、人工改写指令和错误任务指令。
  - **真实机器人**：AgileX PiPER 双臂平台，6 个任务（4 个抓取、2 个堆叠），共享同一视觉场景，使用规范与未见改写指令各评估 5 次。
- **对比方法**：VLA-Adapter、SmolVLA、π0.5，以及 OpenVLA-OFT、X-VLA、Xiaomi-Robotics-0 等报告基线；同时设置 Native、Native+T5、GSR 等变体进行对比。
- **评估指标**：任务成功率，以及官方 **PRIDE** 指标（对改写偏差加权）。

## 4. 资源与算力
- 文中给出了主要训练配置（未见总训练时长/能耗的明确报告）：

  - **SmolVLA GSR**：8× RTX 4090，每卡 batch 16（全局 128），25,000 steps，LR 2e-4。

## 5. 实验数量与充分性
- 实验较为充分，覆盖多个层次：
  - **全 LIBERO-Para 基准评估**（4,092 个 episode），统计上使用配对 McNemar 检验与任务分层 bootstrap 置信区间。
  - **机制诊断**：固定观测下的检索/语义保留分析、层间干预（layerwise patching）、词义子空间控制、语言路由冲突实验（C/C、W/C、C/W）、容量控制消融（增加参数、替换语言源）。
  - **架构迁移验证**：在三种不同信息流架构上验证 GSR，并扩展到真实机器人场景。
  - **ParaVLA** 与标准 VLA 的对比实验。
- **客观性**：严格控制配对条件（相同初始状态、观测、噪声、随机种子），排除记忆化干扰；消融实验证明了收益来自 T5 稳定语义而非额外参数。
- **潜在不足**：真实机器人实验规模较小（每任务 5 次试验），部分任务（如任务 3、5、6）在 GSR 下成功率为 0%，且仅做了有限任务；领域集中在桌面操作，未验证跨具身/大范围开放场景。

## 6. 主要结论与发现
- **性能提升**：GSR 在 LIBERO-Para 上显著提升：VLA-Adapter 从 46.82% → 70.94%，SmolVLA 从 4.47% → 49.12%，π0.5 从 73.60% → 75.59%；成功率最高提升 44.6 个百分点。
- **轻量模型可比肩大规模模型**：VLA-Adapter（非大规模预训练）经 GSR 后接近 π0.5 等超大模型水平；π0.5 在 GSR 下取得最高 PRIDE 分数 **70.4**，超越 Xiaomi-Robotics-0（69.2）。
- **ParaVLA**：0.33B 参数下实现 92% 规范/91% 改写的成功率，几乎无性能下降；在全书 LIBERO-Para 达到 72.51% 和 PRIDE 66.9，优于同规模 VLA。
- **架构性原则总结**：指令应先被独立于当前图像地编码为纯任务语义，然后在多模态融合阶段与视觉场景深度交互，最后重新学习到动作映射；固定的“后接模块”补丁式方案会因架构差异而失效。

## 7. 优点
- **洞察深刻、因果性强**：通过精确的 token 干预与层间替换，直接证明“语义保留但利用失败”，不是停留在相关性分析。
- **方法优雅且高效**：GSR 仅依赖规范演示，不引入任何改写训练数据或一致性损失，结构轻量、开销小。
- **跨架构通用**：在分离式动作策略（VLA-Adapter）、早期多模态交互（SmolVLA）、大规模联合预训练（π0.5）上均有效，并给出了架构感知的明确实施指南。
- **分析细致**：路由冲突实验、词义子空间删除、层间恢复率等，清晰地揭示了不同架构的信息流差异。
- **实践价值**：提出 ParaVLA 证明“彻底解耦”可成为轻量化、鲁棒 VLA 的一种新设计范式。

## 8. 不足与局限
- **规模化瓶颈**：ParaVLA 等解耦架构在增大视觉主干规模时并未表现出 VLM 式的强扩展性，阻止了其成为通用大规模 VLA 的替代。
- **动作专家重新初始化代价**：π0.5 在标准训练步数下规范指令成功率有轻微下降（93→91），需要延长训练才能恢复到 96%，对参数庞大的动作专家不够高效。
- **真实机器人验证非常小**：仅 6 个任务、每任务 5 次重复，且部分任务在多轮试验中成功率始终为 0%，整体统计功效有限。
- **语言源依赖**：GSR 依赖 T5 的语义稳定性，若任务指令超出 T5 的覆盖范围或需要开放世界知识，鲁棒性可能下降。
- **评估范围局限**：主要在 LIBERO 基准和类 LIBERO 桌面操作上验证，未覆盖多样具身、复杂长时程任务或更广泛的中文/多语言指令。
- **其他限制**：如文中未报告完整算力时间、不同模型间训练配置不完全一致（但作者通过配对控制保证对比公平性）等。
