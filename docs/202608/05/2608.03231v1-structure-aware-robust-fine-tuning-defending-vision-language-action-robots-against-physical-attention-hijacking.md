## 摘要
视觉-语言-动作（VLA）策略有望实现通用的机器人操作，但其在面对物理世界攻击时的鲁棒性仍然脆弱。特别是，我们证明物理上可实现的对抗性补丁能够可靠地引发故障，其机制是我们所称的策略关键动作-视觉注意力劫持，即条件于动作的注意力从任务相关区域被转移到局部补丁上。为了证明这一威胁，我们提出了注意力引导的语义破坏（AGSD），这是一种经过期望变换（EOT）优化的可打印补丁，它同时（i）将动作到视觉的注意力集中在补丁上，并且（ii）破坏视觉-语言语义对齐，从而产生强大的跨任务和跨架构迁移能力。为了缓解此类攻击，我们引入了结构感知的鲁棒微调（SARF），这是一种零推理开销的防御方法，仅微调视觉编码器，使用特征锚定、策略关键注意力修正以及限制在语义相关区域的语言引导几何一致性。在LIBERO上，SARF将OpenVLA在AGSD下的失败率从100%降低到14.2%-56.8%（平均28.6%）跨各套件，同时保持干净性能；在真实的PiPER机械臂上，它将AGSD下的平均成功率从23.0%提高到65.0%。这些结果凸显了机制级鲁棒性作为保护VLA机器人免受物理注意力劫持的实用途径。

## Abstract
Vision-Language-Action (VLA) policies promise general robotic manipulation, but their robustness against physical-world attacks remains fragile. In particular, we show that physically realizable adversarial patches can reliably induce failures by triggering a mechanism we call policy-critical action-to-vision attention hijacking, where action-conditioned attention is diverted from task-relevant regions to a localized patch. To demonstrate the threat, we propose Attention-Guided Semantic Disruption (AGSD), an Expectation-over-Transformation (EOT) optimized printable patch that jointly (i) concentrates action-to-vision attention on the patch and (ii) disrupts vision-language semantic alignment, yielding strong cross-task and cross-architecture transfer. To mitigate such attacks, we introduce Structure-Aware Robust Fine-Tuning (SARF), a zero-inference-overhead defense that fine-tunes only the visual encoder using feature anchoring, policy-critical attention correction, and language-guided geometric consistency restricted to semantically relevant regions. On LIBERO, SARF reduces OpenVLA's failure rate under AGSD from 100% to 14.2%-56.8% (28.6% average) across suites while preserving clean performance, and on a real PiPER manipulator it improves average success under AGSD from 23.0% to 65.0%. These results highlight mechanism-level robustness as a practical path to securing VLA robots against physical attention hijacking.

## 2. 方法论

### 2.1 攻击方法：注意力引导语义破坏（AGSD）

**威胁模型**：可打印的局部对抗补丁，经 EOT 优化以满足物理现实性。

补丁注入公式：
```
x' = (1 - m) ⊙ x + m ⊙ δ
```
其中 δ 为补丁图案，m 为二进制空间掩码，⊙ 为逐元素乘。

EOT 优化目标：
```
δ* = argmin_δ E_{t~T} [ L_AGSD(t(x')) ]
```
其中 T 为变换分布（随机旋转、平移、透视、光照抖动等）。

AGSD 总损失函数：
```
L_AGSD = λ_attn · L_attn − λ_disp · L_disp − λ_misalign · L_misalign
```
系数设定：λ_attn = 0.8，λ_disp = 0.2，λ_misalign = 0.5。

三个损失分量：

1. **注意力引导损失（L_attn）** —— 核心攻击组件
   - 直接操纵交叉注意力，迫使动作查询 token 过度关注补丁区域。
   - 计算动作查询集合 Q_act 对补丁内视觉 key token 集合 K_patch 的平均注意力权重，并通过负号最大化该权重。
   - 利用最后三层交叉注意力层的平均权重。

2. **特征分散损失（L_disp）**
   - 采用 InfoNCE 风格的对比损失，最大化对抗图像嵌入与干净图像嵌入之间的余弦距离。
   - 破坏特征空间的语义稳定性。

3. **图文错位损失（L_misalign）**
   - 最大化对抗图像与文本指令嵌入之间对齐程度的偏离。
   - 使对抗图像在联合嵌入空间中与其正确指令解耦。

### 2.2 防御方法：结构感知鲁棒微调（SARF）

**核心设计思想**：
- 只更新视觉编码器，冻结多模态骨干和动作头。
- 使用干净数据预训练的 Teacher 模型引导受扰动 Student 模型的恢复。
- **零推理开销**——训练后部署架构和推理延迟完全不变。

SARF 总损失：
```
L_SARF = λ_feat · L_feat + λ_pcad · L_pcad + λ_geo · L_geo
```
系数设定：λ_feat = 0.5，λ_pcad = 1.0，λ_geo = 0.3。

三个损失分量：

1. **特征锚定损失（L_feat）**
   - 在补丁级别计算 Student 与 Teacher 特征向量的余弦距离（1 − cos θ）。
   - 防止微调过程中的灾难性遗忘，保持特征空间方向一致性。

2. **策略关键注意力蒸馏损失（L_pcad）**
   - **SARF 的核心防御组件**——只针对决定动作输出的动作查询 token 进行注意力蒸馏。
   - 使用对称 Jensen-Shannon 散度（JSD），对齐 Student 与 Teacher 在动作查询到视觉 token 上的注意力分布。
   - 目标：直接抵抗注意力劫持，让策略恢复对任务相关区域的关注。

3. **语言引导几何一致性损失（L_geo）**
   - 利用 Teacher 的文本到视觉注意力构造语言引导的几何掩码（mask），只约束任务相关区域（如末端执行器和操作对象）。
   - 通过 Gram 矩阵元素衡量成对特征关系，最小化 Student 与 Teacher 在掩码区域内几何结构的差异。
   - 优势：自动降权背景扰动，聚焦任务关键对象的结构去噪。

## 6. 主要结论与发现

### 6.1 攻击有效性
- 即使非优化的 Random 补丁也能提高失败率；优化的补丁显著更强。
- **AGSD 将 OpenVLA 在全部四个 LIBERO 套件上推向 100% 失败率**（相对 Random 提升 24.4–64.2 个百分点）。
- AGSD 跨架构迁移能力强：OpenVLA-oft 的 FR 从随机补丁的 10.0–32.0% 升至 93.6–100%；π0 从 5.2–48.6% 升至 48.8–80.2%。
- 与 EDPA 相比，AGSD 在 OpenVLA 上相当，但在 OpenVLA-oft 和 π0 上显著更强，支持了"注意力劫持+语义破坏"联合目标的有效性。

### 6.2 注意力劫持机制确认
- 注意力热力图显示，AGSD 使原始策略的动作-视觉注意力在轨迹各时间步反复坍缩至补丁区域，远离任务相关证据。
- Ablation 证明：单独的注意力引导或单独的语义破坏都有攻击效果，但**两者联合效果最强**，说明两组件互补。

### 6.3 防御有效性（SARF）
- **SARF 将 AGSD 下的 FR 从 100% 降至平均 28.6%**（Spatial 17.0% / Object 14.2% / Goal 26.5% / Long 56.8%），绝对下降 71.4 个百分点。
- 对其他攻击基线同样稳健：UADA 平均 FR 26.8%，UPA 26.0%，EDPA 27.4%。
- **显著优于对抗微调（AF）**：AGSD 下 AF 平均 FR 仍高达 96.6%，而 SARF 仅 28.6%。说明**稳定策略"看向哪里"比单纯对齐"模型表征什么"更有效**。
- 干净性能几乎无损：平均 FR 从 23.2%（Original）微升至 23.5%（SARF）。

### 6.4 真实机器人验证
- 打印 AGSD 补丁将 PiPER 的平均成功率从干净的 72.0% 降至 23.0%。
- SARF 在相同物理补丁下将成功率恢复至 **65.0%**（AF 仅为 40.7%）。
- 各任务均显著提升：pick & place 74.0%（接近干净的 79.0%）、open drawer 63.0%、stack 58.0%（干净为 66.0%，仍留有 8.0 点差距）。

### 6.5 消融发现
- 移除 L_pcad 时，AGSD 下的 FR 从 17.0% 飙升至 87.5% → **策略关键注意力蒸馏是防御的核心组件**。
- 移除 L_feat 导致干净性能严重退化（FR 升至 31.6%）→ 特征锚定主要保证原始能力稳定性。
- 移除 L_geo 导致适度鲁棒性下降（FR 升至 35.8%）→ 几何一致性提供结构约束的补充价值。

## 7. 优点

1. **机制级洞察**：首次系统性地识别并命名了"策略关键动作-视觉注意力劫持"这一 VLA 特有的物理攻击失败机制，超越了以往"全局表征对齐"的分析框架。
2. **攻击设计精妙**：AGSD 联合注意力劫持与语义破坏，在跨任务和跨架构迁移方面优于现有攻击（UADA/UPA/EDPA），且有消融实验支撑各组件贡献。
3. **防御轻量实用**：SARF 只微调视觉编码器，**零推理开销**，部署接口不变，满足实际物理部署需求；这与基于生成模型净化（高开销）或全模型对抗训练（易遗忘）的传统防御形成对比。
4. **评估严谨**：包括自适应攻击再优化、注意力热力图机制级验证、仿真+真实机器人双轨评估、多攻击多架构对比、完整消融。
5. **注意力蒸馏粒度精细**：只蒸馏动作查询 token 上的注意力分布（而非全部注意力），利用掩码将几何一致性限制在语义相关区域，避免了背景噪声干扰。
6. **可复现性考虑**：攻击与防御的损失函数、系数设置、EOT 变换分布都有明确报告。

## 8. 不足与局限

1. **防御范围有限**：SARF 仅在 OpenVLA 上验证，未推广到 π0 等扩散/流式动作模型。作者指出这需要识别相应的"策略关键视觉通路"，但这项工作尚未完成，限制了 SARF 对更广泛 VLA 架构的适用性声明。
2. **长程任务鲁棒性不足**：Long suite 下 SARF 的 FR 仍有 56.8%，是四个套件中最差的。长时程轨迹中注意力抖动会累积，残余补丁注意力泄漏可导致延迟性失败。
3. **算力信息缺失**：未报告 GPU 型号、数量、训练消耗等资源数据，不利于复现成本评估和公平比较。
4. **真实机器人评估覆盖有限**：
   - 仅 3 个桌面操作任务，未覆盖移动操作、

5. **评估未覆盖更广泛的对抗训练威胁模型**：SARF 的鲁棒性评估主要针对补丁类攻击，未覆盖其他物理可实现攻击形式（如光照操纵、相机噪声注入）或数字化攻击，因此其防御边界需进一步明确。
6. **教师模型的依赖假设**：SARF 假设可获取干净数据预训练的 Teacher 模型，这在现实中通常成立，但在离线数据存在分布漂移或教师模型本身被攻击的场景下，防御效果可能退化，论文未探讨此类边界情况。
7. **物理补丁尺寸的敏感性**：真实实验中补丁尺寸从 5×5cm 到 20×20cm 不等，但论文未系统分析补丁尺寸/遮挡面积变化对 SARF 防御裕度的量化影响，实际部署中对补丁规模的鲁棒性边界尚不清晰。
8. **注意力蒸馏的理论保证缺失**：虽然实验证明 L_pcad 有效，但论文未提供关于注意力分布 JSD 蒸馏收敛性、以及蒸馏后注意力恢复与动作误差之间正式的理论联系（如 Lipschitz 边界），结论主要依赖经验证据。

## 9. 总体评价与研究展望

### 总体评价
该论文是一篇结构清晰、机制驱动的鲁棒性研究，其核心贡献在于**将对抗补丁攻击的理解从"表征层"推进到"注意力通路层"**，并据此设计了目标明确、代价极低的防御方案。攻击端（AGSD）和防御端（SARF）形成了具有内在一致性的攻防闭环，即二者都在同一套"动作查询 token → 视觉 token"的交叉注意力信道上施加影响/恢复，这种"以同一机制打、以同一机制防"的对称设计使论文逻辑自洽且说服力强。真实机器人实验进一步验证了从仿真到物理世界的可迁移性，整体上是一篇方法设计、机制分析、实验验证俱佳的工作。

### 局限总结
- 防御范围局限于注意力可显式访问的自回归式 VLA（OpenVLA），对扩散/流式动作骨干的推广尚未实现。
- 长程任务下的残余脆弱性（FR 56.8%）表明注意力稳定性在长时间尺度上仍有挑战。
- 资源消耗与训练成本的披露不足，影响可复现性与工程落地判断。

### 未来研究方向
1. **扩展至通用动作骨干**：将"策略关键视觉通路"的概念类比到扩散/流式解码器（如 π0、Fast）的交叉注意力/去噪噪声预测通路，设计对应的注意力蒸馏目标。
2. **在线自适应防御**：SARF 目前是离线微调方案，未来可探索测试时自适应调节注意力权重或检测注意力坍缩以动态触发防御。
3. **多模态联合语义约束**：在 L_pcad 基础上引入动作级蒸馏（教师与学生动作输出的 KL 散度），形成"注意力 + 动作 + 特征"三层次联合防御。
4. **理论分析深化**：建立对抗补丁导致的注意力扰动与闭环控制稳定性之间正式的定量关系，为鲁棒性提供可验证的数学边界。
5. **更大规模物理实验**：扩展到移动操作、双手操作、以及更复杂多步骤任务，验证 SARF 在更广真实场景中的泛化。
